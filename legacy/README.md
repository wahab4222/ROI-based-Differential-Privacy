# Legacy implementation

These files correspond to the earlier implementation associated with the original manuscript submission and are retained only for historical reproducibility.

The legacy pipeline used separate Flower-based `client.py` and `server.py` scripts and was associated with the earlier OASIS-only, four-class, CBAM/FedProx-oriented experimental design and epsilon-oriented privacy reporting.

These scripts **do not represent the revised JMI experimental pipeline**.

For the revised manuscript, use:

```text
../unified_roi_dp.py
```

Revised archived release:

https://doi.org/10.5281/zenodo.22093150

Legacy epsilon values should not be interpreted as certified `(epsilon, delta)`-differential privacy guarantees in the revised study.
